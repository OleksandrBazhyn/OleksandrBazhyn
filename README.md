### What I've built
- 🔎 **Client data aggregator** — a web service that pulls company data by EDRPOU code from a CRM, QES registries, a licensing portal, the VAT registry and payments; replaced a 5+ minute manual search across 4+ systems. Used daily by the whole team.
- 📅 **Expiry tracker** — shows which M.E.Doc modules and QES certificates expire in a given month, so managers can remind clients on time.
- ⚙️ **Automations** — lead-generation scraper, CRM-connected Telegram bot, Google Apps Script tools.
- ☁️ **Zero-cost, fault-tolerant deployment** — Render + self-hosted Docker behind Cloudflare Tunnel.
- 📚 **RAG legal assistant** (bachelor's thesis) — hybrid search (BM25 + vector), cross-encoder reranking, RAGAS evaluation.
